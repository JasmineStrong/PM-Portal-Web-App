# Card Component Example
**Cards** is a UI design pattern that groups related information in a flexible-size container visually resembling a playing card. (Nielsen Group Norman Group).

````
<div class="grid-card">
   <div class="card-box">
        <img class="icon-fluid" src="assets/img/study Feasibility Icon.svg" />
         <h3>Some Title</h3>
         <p>A short description about the card.</p>
    </div>
</div
````
